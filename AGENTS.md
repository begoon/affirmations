## Commit messages

Always use Conventional Commits: `<type>[optional scope]: <description>`.
Use a concise, imperative description and the appropriate type, such as `feat`,
`fix`, `docs`, `style`, `refactor`, `test`, or `chore`.
Examples: `feat(miniapp): add flashcard navigation` and
`docs: add miniapp screenshots to the guide`.
